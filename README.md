# 🇧🇷 Português-BR

## 💻 Sobre o projeto

O **Custom QR Code Generator** é uma aplicação web moderna desenvolvida com **Next.js**, **React** e **CSS**, projetada para criar códigos QR customizados de alta qualidade. 

Diferente de geradores comuns, esta aplicação permite que o usuário tenha total controle estético sobre o código gerado, possibilitando a inserção de logotipos centralizados, customização completa de paleta de cores (código e fundo) e ajuste de dimensões, tornando-o ideal para empresas que buscam alinhar a identidade visual da marca às suas estratégias digitais. Tudo é processado e exibido **em tempo real** na tela.

---

## ✨ Funcionalidades

- 🔗 **Geração Dinâmica:** Digite ou cole qualquer link/texto para gerar o QR Code instantaneamente.
- 🎨 **Personalização de Cores:** Escolha a cor principal dos módulos do QR Code e a cor de fundo utilizando seletores de cor interativos.
- 🖼️ **Logotipo Centralizado:** Envie uma imagem (PNG/JPEG) do seu computador para ser aplicada diretamente no centro do QR Code.
- 📐 **Ajuste de Escala:** Defina o tamanho exato que a logo deve ocupar no centro para evitar obstrução de leitura.
- ⚡ **Renderização Real-Time:** Veja cada alteração de cor, tamanho ou imagem ser aplicada imediatamente.
- 💾 **Download em Alta Qualidade:** Baixe o QR Code finalizado diretamente como arquivo de imagem pronto para uso digital ou impressão.

---

## 🛠 Tecnologias utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento web moderno:

- **[Next.js](https://nextjs.org/)** – Framework React focado em performance, roteamento e otimização.
- **[React](https://reactjs.org/)** – Biblioteca para construção de interfaces componentizadas e reativas.
- **[TypeScript](https://www.typescriptlang.org/)** – Superconjunto JavaScript que adiciona tipagem estática e segurança ao código.
- **CSS3 / CSS Modules** – Para estilização limpa, responsiva, moderna e isolamento de escopo de estilos.

# 🇺🇸 English

## 💻 About the project

The **Custom QR Code Generator** is a modern web application built with **Next.js**, **React**, and **CSS**, designed to create high-quality, customized QR codes.

Unlike standard generators, this application grants users full aesthetic control over the generated code. It allows for centered logo integration, complete color palette customization (foreground and background), and dimension adjustments, making it an ideal tool for businesses looking to align their brand identity with their digital strategies. Everything is processed and rendered **in real-time** on the screen.

---

## ✨ Features

- 🔗 **Dynamic Generation:** Type or paste any link/text to generate a QR code instantly.
- 🎨 **Color Customization:** Choose the primary color of the QR code modules and the background color using interactive color pickers.
- 🖼️ **Centered Logo:** Upload an image (PNG/JPEG) from your computer to be applied directly to the center of the QR code.
- 📐 **Scale Adjustment:** Define the exact size the logo should occupy in the center to ensure readability.
- ⚡ **Real-Time Rendering:** See every color, size, or image change applied immediately.
- 💾 **High-Quality Download:** Download the finished QR code directly as an image file, ready for digital use or printing.

---

## 🛠 Technologies Used

The project was built using modern web development best practices:

- **[Next.js](https://nextjs.org/)** – A React framework focused on performance, routing, and optimization.
- **[React](https://reactjs.org/)** – A library for building component-based and reactive interfaces.
- **[TypeScript](https://www.typescriptlang.org/)** – A JavaScript superset that adds static typing and code security.
- **CSS3 / CSS Modules** – For clean, responsive, modern styling and scoped style isolation.
